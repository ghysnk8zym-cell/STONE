# Phase 3 — Home, Catalog and Product Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the public Home v2, Catalog and 12 Product pages (with the cost calculator) in ru/en, faithful to Figma at 1440 / 1024 / 768 / 390, server-rendered over a static catalog repository.

**Architecture:** a `CatalogRepository` interface in `src/server/catalog/` with a static seed implementation (Phase 4 swaps in the database). Pages are server components under `src/app/[locale]/`; catalog filter state lives in URL search params read by the server; client islands only for the calculator, carousels, gallery and filter auto-submit. The calculator is a pure function in `src/lib/calculator.ts`. Shell (header, footer, tab bar) moves into `[locale]/layout`.

**Tech Stack:** Next.js 16.3.8 App Router, React 19, Tailwind CSS 4.3, next-intl 4, zod 4 (already present), Vitest 5 + Testing Library, Playwright 1.64 + axe, existing `scripts/visual-compare.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-14-phase-3-pages-design.md` (+ Phase 0 spec, `docs/FIGMA-INVENTORY.md`, `docs/ARCHITECTURE.md` "Layout notes for Phase 3", `docs/QA/phase-2-components.md`).

## Review Focus

1. A shared catalog URL with a garbage or stale value (`?material=granite&sort=foo`) must render the full catalog, not a 500. → Task 1 unit `parseCatalogQuery drops unknown values`, Task 6 e2e `invalid params render the catalog`.
2. A Russian user types `2,5` (comma) and clears the field mid-edit: no NaN, no stale total. → Task 2 unit `parses comma decimals` and `empty input is invalid`, Task 7 e2e `clearing the area shows an error and a dash`.
3. Switching language on a filtered catalog must keep the filter. → Task 4 e2e `language switch keeps path and query`.
4. A ru product name longer than the card at 360 must not overflow. → Task 6 e2e `no horizontal overflow at 360 in ru`.
5. Without JavaScript the catalog filters and the calculator default must still work. → Task 6 e2e `filters apply without JavaScript`, Task 7 e2e `calculator default is server-rendered`.

```ts
export type Material = "marble" | "limestone" | "slate" | "sandstone" | "quartzite" | "concrete"; // exact set = values on the Catalog screen
export type Color = string-literal union from the product screens;   // e.g. "black" | "grey" | "charcoal" | …
export type Finish = string-literal union from the product screens;  // e.g. "polished" | "split-face" | …
export type CatalogSort = "name-asc" | "name-desc" | "price-asc" | "price-desc";
export type Product = {
  slug: string; material: Material; color: Color; finish: Finish;
  formatMm: readonly [number, number, number];
  priceCents: number; oldPriceCents?: number; isPlaceholder: true;
  images: readonly string[];            // manifest keys, first = main
  imageFit: "cover" | "contain";        // contain for the studio slabs (Black Marble, Grey Limestone, Grey Marble)
  figmaNode: string;                    // 1440 product screen
};
export type CatalogQuery = { material?: Material; color?: Color; finish?: Finish; sale?: true; sort: CatalogSort; q?: string };
export type Localizer = { name(slug: string): string; material(m: Material): string };
export interface CatalogRepository {
  list(query: CatalogQuery, l10n: Localizer): Promise<Product[]>;
  getBySlug(slug: string): Promise<Product | null>;
  listFeatured(): Promise<Product[]>;   // Home "Catalog" carousel, Figma order
  listPromo(): Promise<Product[]>;      // products with oldPriceCents, Figma Home order
  facets(): Promise<{ materials: Material[]; colors: Color[]; finishes: Finish[] }>; // values present in data, sorted
  total(): Promise<number>;
}
export function parseCatalogQuery(params: Record<string, string | string[] | undefined>): CatalogQuery;
export function discountPercent(p: Product): number | undefined; // round((old-price)/old*100)
export const catalog: CatalogRepository; // index.ts: the static implementation
```

### Task 2: Calculator and money

```ts
export type CalcInput = { mode: "area"; area: string } | { mode: "wall"; length: string; height: string };
export type CalcField = "area" | "length" | "height";
export type CalcResult =
  | { ok: true; surfaceM2: number; extraM2: number; orderM2: number; unitCents: number; totalCents: number }
  | { ok: false; field: CalcField; reason: "invalid" | "range" };
export const EXTRA_RATE = 0.1;
export const LIMITS = { area: [0.01, 10_000], length: [0.01, 100], height: [0.01, 100] } as const;
export function parseDecimal(input: string): number | null; // "2.5", "2,5", " 2 " ok; "", "2,5,1", "abc", "1e3" → null
export function calculate(input: CalcInput, unitCents: number): CalcResult;
```
